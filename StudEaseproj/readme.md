# StudEase 🎓

StudEase is a responsive college guide website designed to simplify student life.
It provides information about nearby mess options, college events, clubs and
communities, city happenings, and more.

## 🔧 Tech Stack
- HTML5
- CSS3 (Flexbox & Grid)

## ✨ Features
- Responsive design (mobile, tablet, desktop)
- Clean UI with modern gradients
- Reusable components
- Smooth navigation
- College-friendly project structure

## 📁 Pages
- Home
- Nearby Mess
- College Events
- Clubs & Communities
- City Happenings
- About Us
